## Introduction

**Pokémon Conglomerate** is a Pokémon-themed application that brings together several useful tools and features in one place.

The project is designed to provide a simple and easy-to-use interface for exploring Pokémon information and performing different calculations.

---

## Functions

* **Pokédex** — Search and view information about Pokémon.
* **Catch Rate Calculator** — Calculate the probability of catching a Pokémon.
